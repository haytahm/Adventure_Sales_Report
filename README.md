# 📊 Sales Performance Dashboard (Power BI + SQL)

This project is a sales performance dashboard built with **Power BI**, using data analysis techniques and **SQL** preprocessing.

## 🔧 Tools Used
- Power BI for visualization
- SQL for data transformation
- Excel for raw data storage

## 📌 Features
- Sales vs Target performance
- Sales breakdown by Customer, Product, Category, and City
- Interactive filters (Category, City, Product)
- Monthly performance tracking
- Geographic mapping with customer distribution

## 📂 Files Included
- `Sales_Dashboard.pbix`: Power BI Dashboard file
- `sales_data.xlsx`: Sample sales data (anonymized)
- `queries.sql`: SQL scripts used for data transformation
